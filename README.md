# FreeMVVM

Rust Coreとversioned C ABIを通じて、C++ / C# / Rust / Pythonから共通MVVM UIを扱うライブラリです。現在は設計と開発基盤の段階で、製品APIは未実装です。

- [詳細設計](.docs/13_detail_design/README.md)
- [テスト設計](.docs/32_unit_test/README.md)

ローカルで生成するnative library / managed assembly / wheelは開発用の空の骨格です。正式配布物、Runtime 1.0、実装済みABIとして扱わないでください。
