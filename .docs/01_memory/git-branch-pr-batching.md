# Git運用の学び: 関連TodoのPR集約とマージ済みブランチ整理

- 対象: freemvvmの複数言語wrapper等を横断する実装計画、Gitブランチ・PR運用。
- 関連ルール: [Git管理ルール](../02_git/rule.md)。
- 同じ大きな計画に属する関連Todoは、言語・依存層ごとに適切なブランチへ分けても、各Todo単位ですぐPRにせず、計画全体のTodo完了後にレビュー可能なまとまりとしてPRを発行する。
- 実装unitの対応テストが完了したら、応答ごとに日本語commitし、その作業ブランチへpushする。branch pushとmain向けPRのタイミングは別である。
- 言語wrapperブランチは対象変更に必要な最新Core APIブランチから分岐し、別言語wrapperブランチを親にしない。
- PRがmainへ反映されたことを確認後、不要な作業ブランチを整理する。未マージの子ブランチの親、進行中の作業、別案件ブランチは保持する。
