# 分類: Core Runtime / Property Validator

同期Validator callbackは利用者コードなので、`ui_objects` lockを保持したまま実行しない。PropertyからcallbackのArcをsnapshotしてlockを外し、Runtime単位のactive guardでsetterやBinding/Subscription変更の再入を拒否してから、commit用lockを再取得する。

kindを先に確認し、一致候補は同値を含めvalidatorへ渡す。受理した同値候補は既存表現を保ち、拒否候補は値とnotification queueを変更しない。C ABI registration handleをreleaseしてもvalidatorは解除せず、明示cancelでPropertyから外す。初期Binding validatorは対象candidateとvalidatorをlock内でsnapshotし、lockを解放してcallbackを実行してからBindingをpublishする。callback再入guardがあるためpreflightとpublishの間にPropertyやBindingを変更できない。

BOOL/I64/UTF8 callbackは共通のimmutable validation Errorを返せる。Coreはcallbackが返したerror handleを検証し、invalid status時には有効なErrorを消費して`UI_INTERNAL_ERROR`へ写像する。C ABI setterとBinding createは拒否Errorをcallerへ渡し、optional outputがnullなら内部でreleaseする。Binding後続propagationのerror snapshotは別実装単位。
