# RQ-13: 非機能要求と実測

- 文書版: 0.4
- 状態: 承認済み（利用者、2026-10-17）
- 更新日: 2026-10-17
- 入口: [要求仕様索引](reqirements-specification.md)

## 概要

代表的なARM board上で、同一の製品機能を対象に性能・安定性を実測する。測定値と数値保証の合否を分け、性能特性を実装言語だけで説明せず、処理層ごとに把握できるようにする。

本章は提供機能・利用条件・外部から観測できる結果を定める。各IDの対象段階を区別し、将来候補の列挙を採用承認とはしない。
