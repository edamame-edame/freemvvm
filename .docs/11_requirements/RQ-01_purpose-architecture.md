# RQ-01: 目的と共通アーキテクチャ

- 文書版: 0.4
- 状態: 承認済み（利用者、2026-10-17）
- 更新日: 2026-10-17
- 入口: [要求仕様索引](reqirements-specification.md)

## 概要

対応言語と共通MVVM UIとして利用者に提供する範囲、およびRust Coreと各言語の公開境界に関する製品上の制約を定める。個別機能の振る舞いは各要求章で定義する。

本章は提供機能・利用条件・外部から観測できる結果を定める。各IDの対象段階を区別し、将来候補の列挙を採用承認とはしない。

## 要求本文

| 要求ID | 項目 | 要求詳細 | 対象段階 |
| --- | --- | --- | --- |
| <a id="rq-01-001"></a>RQ-01-001 | 4言語で共通のMVVM UIを利用できる | C++、C#、Rust、Python 3の各利用者が、同じMVVMの基本機能とUIシナリオを使えること。利用可能なプラットフォーム上で共通のUIライブラリとして動作し、言語ごとのAPI表現が異なっても、Property、Binding、CommandおよびUIの利用結果に意味上の差を生じさせないこと。 | 現行 |
| <a id="rq-01-002"></a>RQ-01-002 | 共通ランタイムと安定した言語間境界を提供する | 共通UIランタイムはRustで実装する。言語ごとの利用層はversioned C ABIを介して共通ランタイムを利用し、各言語のAPI型・例外・オブジェクト表現をABI境界へ持ち出さないこと。利用者から見た機能状態の正本は共通ランタイムにあり、言語層ごとに独立した状態や通知規則を持たないこと。 | 現行 |

## 適用境界

承認は要求本文の範囲で完結する。API名・内部データ構造・処理方式の確定を前提にしない。既存ADRによるRust Core・versioned C ABI等の明示的な構成制約は維持する。
